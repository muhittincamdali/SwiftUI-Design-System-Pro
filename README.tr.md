DesignSystemPro, tutarlı bir görünümü sıfırdan kurmak istemeyen SwiftUI uygulamaları için bir Swift
paketidir. İçinde tasarım token'ları (renkler, tipografi, boşluklar, kenarlıklar, gölgeler, animasyon),
açık, koyu, hazır ve marka temalarını yöneten bir tema motoru ve bu token'lar üzerine kurulu yaklaşık 40
bileşen görünümü bulunur: düğmeler, metin alanları, anahtarlar, kartlar, rozetler, avatarlar, toast
bildirimleri ve iskelet yükleyiciler. Her bileşen renklerini açık ve koyu moda göre seçer; tipografi
token'larıyla biçimlenen metinler Dynamic Type'a uyar.

## Öne çıkanlar

- **Açık ve koyu mod** — her renk token'ının açık, koyu ve yüksek kontrastlı bir değeri vardır;
  bileşenler doğru olanı ortamdan (environment) alır.
- **Dynamic Type** — `dsTypography(_:)`, yazı stillerini kullanıcının metin boyutu ayarına göre ölçekler.
- **Kendi görünümleriniz için temalar** — `ThemeManager` sistemi izler ya da hazır bir temayı veya
  marka renklerinizden üretilen bir temayı uygular; temayı `@Environment(\.dsTheme)` ile okursunuz.
- **Kontrast kontrolü** — `ColorContrastUtility` WCAG kontrast oranlarını hesaplar; testler gövde
  metnini ve dolu düğme etiketlerini iki renk şemasında da WCAG AA'ya göre denetler.
- **Test edilen çizim** — bir test, her bileşen grubunu açık ve koyu modda çizip kayıtlı referans parmak
  izleriyle karşılaştırır; bir renk ya da yerleşim değişikliği CI'ı kırmızıya düşürür.
- **Beş platform** — iOS, macOS, tvOS, watchOS ve visionOS, çalışma zamanı bağımlılığı olmayan tek bir
  pakette.

## Hızlı başlangıç

**1. Paketi ekleyin**

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

**Dependency Rule** alanını 2.0.0'dan başlayan **Up to Next Major Version** olarak bırakın ve
**Add Package** düğmesine basın. Açılan pencerede **DesignSystemPro** satırında uygulama hedefinizi
seçin ve yeniden **Add Package**'a basın.

**2. Modülü içe aktarın**

Bileşenleri kullandığınız Swift dosyasının en üstüne şu satırı ekleyin:

```swift
import DesignSystemPro
```

**3. Kullanın**

Yeni bir SwiftUI uygulama projesindeki `ContentView.swift` dosyasının içeriğini aşağıdaki kodla
değiştirin ve uygulamayı çalıştırın (**Product › Run**, ⌘R). Ekranda bir başlık, yeşil bir "Ready"
rozeti, bir anahtar ve anahtarı açıp kapatan tam genişlikte bir düğme görürsünüz.

```swift
import DesignSystemPro
import SwiftUI

struct ContentView: View {
    @State private var notificationsOn = true

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Hello, DesignSystemPro")
                .dsTypography(TypographyTokens.Heading.h2)

            DSStatusBadge("Ready", variant: .success)

            DSToggle(isOn: $notificationsOn, label: "Notifications")

            DSButton("Continue", isFullWidth: true) {
                notificationsOn.toggle()
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
    }
}
```

Aynı dosya örnek uygulamada da var:
[Examples/DesignSystemProDemo/Sources/ContentView.swift](Examples/DesignSystemProDemo/Sources/ContentView.swift).

## Kurulum

### Swift Package Manager

Xcode'da **File › Add Package Dependencies…** menüsünü seçin ve depo adresini girin:

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

Ya da `Package.swift` dosyanızdaki `dependencies` listesine ekleyin:

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "DesignSystemPro", package: "SwiftUI-Design-System-Pro")
    ])
]
```

2.0.0'dan önceki sürümler, bu README'nin anlatmadığı eski 1.x API'sini içerir.

## Kullanım

### Tema sağlayıcısını ve toast katmanını kurun

Kök görünümü `DSApp` ile sarın. `DSApp` etkin temayı ortama koyar ve toast bildirimlerini gösteren
katmanı ekler:

```swift
import DesignSystemPro
import SwiftUI

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            DSApp { ContentView() }
        }
    }
}
```

### Bileşenlerle bir ekran kurun

Bileşenler düz değerler ve binding'ler alır; boşluk ve yazı token'lardan gelir. Örnek uygulamadaki
giriş ekranı şöyledir:

```swift
struct SignInView: View {
    @State private var email = ""
    @State private var isSubmitting = false

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Welcome back").dsTypography(TypographyTokens.Heading.h2)

            DSTextField("Email", text: $email, placeholder: "you@example.com")

            DSButton("Sign in", isFullWidth: true) {
                isSubmitting = true
                DSToastManager.shared.success("Signed in")
            }
            .loading(isSubmitting)

            HStack {
                DSAvatar(name: "Ada Lovelace", status: .online)
                DSStatusBadge("Verified", variant: .success)
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .dsBackgroundColor(ColorTokens.Background.primary)
    }
}
```

### Tema seçin

`ThemeManager`, siz bir tema belirleyene kadar sistemin açık/koyu ayarını izler:

```swift
// Follow the system light/dark setting (the default) ...
DesignSystemPro.configure()

// ... or force a preset or a generated brand theme.
ThemeManager.shared.setTheme(PresetThemes.ocean)

let brand = BrandConfiguration(primaryColor: .purple, secondaryColor: .pink, borderRadius: 12)
ThemeManager.shared.setTheme(WhiteLabelConfiguration(brand: brand, appName: "Acme").darkTheme)
```

Kendi görünümleriniz etkin temayı `@Environment(\.dsTheme)` ile okur. Hazır bileşenler renk
token'larını doğrudan kullanır; tema onların görünümünü değiştirmez.

### Kontrastı denetleyin

```swift
let ratio = ColorContrastUtility.contrastRatio(.white, Color(hex: "#2563EB")) // about 5.2
let passes = ColorContrastUtility.meetsWCAG_AA(.white, Color(hex: "#2563EB")) // true
```

[Tests/DesignSystemProTests/ReadmeExamples.swift](Tests/DesignSystemProTests/ReadmeExamples.swift)
tarafından derlenir ve çalıştırılır.

## Mimari

```text
Sources/DesignSystemPro
├── Tokens/      ColorTokens, TypographyTokens, SpacingTokens, BorderTokens, ShadowTokens, AnimationTokens
├── Theme/       DSTheme, ThemeManager, DSThemeProvider, presets, brand/white-label generation
├── Components/  Buttons, text input, selection, cards, badges, avatars, toasts, skeletons
└── DesignSystemPro.swift   configure() and DSApp
```

| Aile          | Görünümler                                                                                                                 |
| ------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Düğmeler      | `DSButton` (6 varyant, 5 boyut, ikonlar, yükleniyor durumu), `DSIconButton`, `DSButtonGroup`                               |
| Metin girişi  | `DSTextField` (doğrulama durumları, gizli giriş), `DSTextArea`, `DSSearchField`, `DSOTPField`                              |
| Seçim         | `DSToggle`, `DSSwitch`, `DSCheckbox`, `DSCheckboxGroup`, `DSRadio`, `DSRadioGroup`                                         |
| İçerik        | `DSCard`, `DSCardHeader`, `DSCardFooter`, `DSStatCard`, `DSMediaCard`, `DSListCard`, `DSCardListItem`                      |
| Rozetler      | `DSBadge`, `DSCounterBadge`, `DSDotBadge`, `DSStatusBadge`, `DSTag`                                                        |
| Avatarlar     | `DSAvatar` (görsel, baş harfler ya da yer tutucu, durum noktası), `DSAvatarGroup`, `DSBorderedAvatar`, `DSAvatarWithBadge` |
| Geri bildirim | `DSToastManager` ile `DSToastContainer`/`DSToastView`, `DSSnackbar`                                                        |
| Yükleme       | `DSSkeleton` ve metin, avatar, kart, liste, tablo ve profil iskeletleri; `DSConditionalSkeleton`                           |

- Bileşenler token'lardan kurulur ve temayı okumaz. Token'lar düz `Sendable` değer tipleridir.
- `ThemeManager` ve `DSToastManager`, paylaşılan örnekleri ve public başlatıcıları olan `@MainActor`
  `@Observable` sınıflardır; bu sayede dışarıdan verilebilir (`DSThemeProvider(themeManager:)`,
  `DSToastContainer(manager:)`) ve test edilebilirler.
- Testler (`swift test`) Swift Testing kullanır: token hesapları, kontrast, tema çözümleme, toast kuyruğu
  ve zamanlayıcıları, bileşen yardımcıları, dokümantasyondaki kod parçaları, her bileşen grubunun açık ve
  koyu moddaki referans parmak izleri ve tema sağlayıcısı, anahtar rengi ve OTP odak çerçevesi için
  AppKit içinde barındırılan görünümler. CI bunları bir iOS simülatöründe de çalıştırır.

## Yol haritası

- Bileşenlerin etkin temayı okuması; böylece hazır ve marka temaları onları da yeniden biçimlendirir.
- Açık palet renkleri üzerindeki avatar baş harflerinin ve koyu moddaki onay kutusu işaretinin
  kontrastını WCAG AA düzeyine çıkarmak.

Paket Haziran 2026'da yer tutucu dosyalara indirgenmişti; 2.0 önceki token'ları, tema motorunu ve
bileşenleri geri getirir, bu sırada bulunan hataları düzeltir ve testleri ekler. 1.x API'sindeki
bileşenler (uyarılar, modal pencereler, gezinme çubuğu, sekme çubuğu, grafikler) geri getirilmedi. Fikir
ve hata bildirimlerinizi [issue](https://github.com/muhittincamdali/SwiftUI-Design-System-Pro/issues)
olarak açabilirsiniz.
