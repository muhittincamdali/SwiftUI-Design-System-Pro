DesignSystemPro は、統一感のある見た目を一から作らずに済ませたい SwiftUI アプリのための Swift パッケージです。デザイントークン（カラー、タイポグラフィ、余白、枠線、影、モーション）、ライト・ダーク・プリセット・ブランドのテーマを扱うテーマエンジン、そしてトークンの上に作られた約 40 個のコンポーネントビュー（ボタン、テキストフィールド、トグル、カード、バッジ、アバター、トースト、スケルトンローダー）が含まれています。どのコンポーネントもライトモードとダークモードに合わせて色を切り替え、タイポグラフィトークンで装飾したテキストは Dynamic Type に追従します。

## 主な特長

- **ライトモードとダークモード**：すべてのカラートークンがライト・ダーク・高コントラストの 3 つの値を持ち、コンポーネントは環境から適切な値を選びます。
- **Dynamic Type**：`dsTypography(_:)` はユーザーの文字サイズ設定に合わせて書体スタイルを拡大縮小します。
- **自作ビュー向けのテーマ**：`ThemeManager` はシステムに追従するか、プリセットやブランドカラーから生成したテーマを適用します。`@Environment(\.dsTheme)` で読み取れます。
- **コントラストチェック**：`ColorContrastUtility` は WCAG のコントラスト比を計算します。テストでは本文テキストと塗りつぶしボタンのラベルを、両方の配色で WCAG AA と照合しています。
- **テスト済みの描画**：各コンポーネントグループをライトとダークで描画し、保存済みの参照フィンガープリントと比較するテストがあります。色やレイアウトが変わると CI が失敗します。
- **5 つのプラットフォーム**：iOS、macOS、tvOS、watchOS、visionOS を、実行時の依存関係がない 1 つのパッケージでサポートします。

## クイックスタート

**1. パッケージを追加する**

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

**Dependency Rule** は **Up to Next Major Version**（2.0.0 から）のままにして **Add Package** をクリックします。次のウィンドウで **DesignSystemPro** の行にアプリのターゲットを選び、もう一度 **Add Package** をクリックします。

**2. モジュールをインポートする**

コンポーネントを使う Swift ファイルの先頭に次の行を追加します。

```swift
import DesignSystemPro
```

**3. 使ってみる**

新しい SwiftUI アプリプロジェクトの `ContentView.swift` の中身を次のコードに置き換え、アプリを実行します（**Product › Run**、⌘R）。見出し、緑色の「Ready」バッジ、トグル、そしてトグルを切り替える幅いっぱいのボタンが表示されます。

```swift
import DesignSystemPro
import SwiftUI

struct ContentView: View {
    @State private var notificationsOn = true

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Hello, DesignSystemPro")
                .dsTypography(TypographyTokens.Heading.h2)

            DSStatusBadge("Ready", variant: .success)

            DSToggle(isOn: $notificationsOn, label: "Notifications")

            DSButton("Continue", isFullWidth: true) {
                notificationsOn.toggle()
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
    }
}
```

同じファイルはサンプルアプリにもあります：
[Examples/DesignSystemProDemo/Sources/ContentView.swift](Examples/DesignSystemProDemo/Sources/ContentView.swift)。

## インストール

### Swift Package Manager

Xcode で **File › Add Package Dependencies…** を選び、リポジトリの URL を入力します。

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

または `Package.swift` の `dependencies` に追加します。

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git", from: "2.0.0")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "DesignSystemPro", package: "SwiftUI-Design-System-Pro")
    ])
]
```

2.0.0 より前のバージョンは、この README では扱っていない旧 1.x API です。

## 使い方

### テーマプロバイダーとトーストのオーバーレイを組み込む

ルートビューを `DSApp` で囲みます。`DSApp` は現在のテーマを環境に設定し、トーストを表示するオーバーレイを追加します。

```swift
import DesignSystemPro
import SwiftUI

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            DSApp { ContentView() }
        }
    }
}
```

### コンポーネントで画面を組み立てる

コンポーネントは通常の値とバインディングを受け取り、余白と文字はトークンから決まります。次はサンプルアプリのサインイン画面です。

```swift
struct SignInView: View {
    @State private var email = ""
    @State private var isSubmitting = false

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Welcome back").dsTypography(TypographyTokens.Heading.h2)

            DSTextField("Email", text: $email, placeholder: "you@example.com")

            DSButton("Sign in", isFullWidth: true) {
                isSubmitting = true
                DSToastManager.shared.success("Signed in")
            }
            .loading(isSubmitting)

            HStack {
                DSAvatar(name: "Ada Lovelace", status: .online)
                DSStatusBadge("Verified", variant: .success)
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .dsBackgroundColor(ColorTokens.Background.primary)
    }
}
```

### テーマを選ぶ

テーマを設定するまで、`ThemeManager` はシステムのライト／ダーク設定に従います。

```swift
// Follow the system light/dark setting (the default) ...
DesignSystemPro.configure()

// ... or force a preset or a generated brand theme.
ThemeManager.shared.setTheme(PresetThemes.ocean)

let brand = BrandConfiguration(primaryColor: .purple, secondaryColor: .pink, borderRadius: 12)
ThemeManager.shared.setTheme(WhiteLabelConfiguration(brand: brand, appName: "Acme").darkTheme)
```

自作のビューは `@Environment(\.dsTheme)` で現在のテーマを読み取ります。組み込みのコンポーネントはカラートークンを直接使うため、テーマによって見た目は変わりません。

### コントラストを確認する

```swift
let ratio = ColorContrastUtility.contrastRatio(.white, Color(hex: "#2563EB")) // about 5.2
let passes = ColorContrastUtility.meetsWCAG_AA(.white, Color(hex: "#2563EB")) // true
```

[Tests/DesignSystemProTests/ReadmeExamples.swift](Tests/DesignSystemProTests/ReadmeExamples.swift)
でコンパイル・実行されています。

## アーキテクチャ

```text
Sources/DesignSystemPro
├── Tokens/      ColorTokens, TypographyTokens, SpacingTokens, BorderTokens, ShadowTokens, AnimationTokens
├── Theme/       DSTheme, ThemeManager, DSThemeProvider, presets, brand/white-label generation
├── Components/  Buttons, text input, selection, cards, badges, avatars, toasts, skeletons
└── DesignSystemPro.swift   configure() and DSApp
```

| ファミリー     | ビュー                                                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| ボタン         | `DSButton`（6 種類のバリアント、5 種類のサイズ、アイコン、読み込み状態）、`DSIconButton`、`DSButtonGroup`                    |
| テキスト入力   | `DSTextField`（検証状態、セキュア入力）、`DSTextArea`、`DSSearchField`、`DSOTPField`                                         |
| 選択           | `DSToggle`、`DSSwitch`、`DSCheckbox`、`DSCheckboxGroup`、`DSRadio`、`DSRadioGroup`                                           |
| コンテンツ     | `DSCard`、`DSCardHeader`、`DSCardFooter`、`DSStatCard`、`DSMediaCard`、`DSListCard`、`DSCardListItem`                        |
| バッジ         | `DSBadge`、`DSCounterBadge`、`DSDotBadge`、`DSStatusBadge`、`DSTag`                                                          |
| アバター       | `DSAvatar`（画像、イニシャル、プレースホルダー、ステータスドット）、`DSAvatarGroup`、`DSBorderedAvatar`、`DSAvatarWithBadge` |
| フィードバック | `DSToastManager` と `DSToastContainer`／`DSToastView`、`DSSnackbar`                                                          |
| 読み込み       | `DSSkeleton` と、テキスト・アバター・カード・リスト・テーブル・プロフィールのスケルトン、`DSConditionalSkeleton`             |

- コンポーネントはトークンから作られており、テーマは読み取りません。トークンはシンプルな `Sendable` の値型です。
- `ThemeManager` と `DSToastManager` は `@MainActor` `@Observable` クラスで、共有インスタンスと公開イニシャライザーを持ちます。そのため注入（`DSThemeProvider(themeManager:)`、`DSToastContainer(manager:)`）もテストもできます。
- テスト（`swift test`）は Swift Testing を使い、トークンの計算、コントラスト、テーマの解決、トーストのキューとタイマー、コンポーネントのヘルパー、ドキュメント内のコード、各コンポーネントグループのライト／ダークの参照フィンガープリント、そしてテーマプロバイダー・スイッチの色・OTP のフォーカス枠を確認するために AppKit 上でホストしたビューを対象にしています。CI では iOS シミュレーターでも実行します。

## ロードマップ

- コンポーネントが現在のテーマを読み取るようにし、プリセットやブランドテーマでコンポーネントの見た目も変わるようにする。
- 明るいパレット色の上にあるアバターのイニシャルと、ダークモードのチェックボックスのチェックマークのコントラストを WCAG AA まで上げる。

このパッケージは 2026 年 6 月にプレースホルダーのファイルだけになっていました。2.0 では以前のトークン、テーマエンジン、コンポーネントを復元し、その過程で見つかった不具合を修正し、テストを追加しています。1.x API のコンポーネント（アラート、モーダル、ナビゲーションバー、タブバー、チャート）は復元していません。アイデアや不具合の報告は [issue](https://github.com/muhittincamdali/SwiftUI-Design-System-Pro/issues) でお寄せください。
