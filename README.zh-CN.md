DesignSystemPro 是一个 Swift 软件包，适合希望界面风格统一、又不想从零搭建的 SwiftUI 应用。它包含设计令牌（颜色、字体、间距、边框、阴影、动效），一个支持浅色、深色、预设和品牌主题的主题引擎，以及基于这些令牌构建的约 40 个组件视图：按钮、文本输入框、开关、卡片、徽章、头像、Toast 提示和骨架屏。每个组件都会按浅色或深色模式解析颜色，使用字体令牌设置样式的文本会跟随 Dynamic Type 缩放。

## 亮点

- **浅色与深色模式**：每个颜色令牌都有浅色、深色和高对比度三个取值，组件会从环境中选取合适的一个。
- **Dynamic Type**：`dsTypography(_:)` 会按用户的文字大小设置缩放字体样式。
- **为你自己的视图提供主题**：`ThemeManager` 可以跟随系统，也可以应用预设主题或由品牌色生成的主题；通过 `@Environment(\.dsTheme)` 读取。
- **对比度检查**：`ColorContrastUtility` 计算 WCAG 对比度；测试会在两种配色方案下按 WCAG AA 检查正文文字和实心按钮的标签。
- **经过测试的渲染**：有一个测试会在浅色和深色模式下渲染每组组件，并与保存的参考指纹比较，颜色或布局一旦变化，CI 就会失败。
- **五个平台**：iOS、macOS、tvOS、watchOS 和 visionOS 共用一个软件包，没有运行时依赖。

## 快速开始

**1. 添加软件包**

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

把 **Dependency Rule** 设为 **Branch** 并输入 `main`，然后点击 **Add Package**。在接下来的窗口中，在 **DesignSystemPro** 一行选择你的应用 target，再次点击 **Add Package**。（使用这套 API 的首个版本 2.0.0 尚未打标签；打标签后，请改选 **Up to Next Major Version**。）

**2. 导入模块**

在使用组件的 Swift 文件顶部加入这一行：

```swift
import DesignSystemPro
```

**3. 开始使用**

新建一个 SwiftUI 应用项目，用下面的代码替换 `ContentView.swift` 的内容，然后运行应用（**Product › Run**，⌘R）。你会看到一个标题、一个绿色的“Ready”徽章、一个开关，以及一个可以切换开关状态的全宽按钮。

```swift
import DesignSystemPro
import SwiftUI

struct ContentView: View {
    @State private var notificationsOn = true

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Hello, DesignSystemPro")
                .dsTypography(TypographyTokens.Heading.h2)

            DSStatusBadge("Ready", variant: .success)

            DSToggle(isOn: $notificationsOn, label: "Notifications")

            DSButton("Continue", isFullWidth: true) {
                notificationsOn.toggle()
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
    }
}
```

示例应用中也有同样的文件：
[Examples/DesignSystemProDemo/Sources/ContentView.swift](Examples/DesignSystemProDemo/Sources/ContentView.swift)。

## 安装

### Swift Package Manager

在 Xcode 中选择 **File › Add Package Dependencies…**，然后输入仓库地址：

```text
https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git
```

或者将其添加到 `Package.swift` 的 `dependencies` 中：

```swift
dependencies: [
    .package(url: "https://github.com/muhittincamdali/SwiftUI-Design-System-Pro.git", branch: "main")
],
targets: [
    .target(name: "YourApp", dependencies: [
        .product(name: "DesignSystemPro", package: "SwiftUI-Design-System-Pro")
    ])
]
```

最新的标签 1.0.0 是旧的 1.x API，本 README 并未介绍它。在 2.0.0 打标签之前请使用 `branch: "main"`，之后改用 `from: "2.0.0"`。

## 使用方法

### 安装主题提供者和 Toast 覆盖层

用 `DSApp` 包裹根视图。它会把当前主题放入环境，并添加用于显示 Toast 的覆盖层：

```swift
import DesignSystemPro
import SwiftUI

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            DSApp { ContentView() }
        }
    }
}
```

### 用组件搭建界面

组件接收普通的值和绑定，间距和字体来自令牌。下面是示例应用中的登录界面：

```swift
struct SignInView: View {
    @State private var email = ""
    @State private var isSubmitting = false

    var body: some View {
        VStack(spacing: SpacingTokens.Content.comfortable) {
            Text("Welcome back").dsTypography(TypographyTokens.Heading.h2)

            DSTextField("Email", text: $email, placeholder: "you@example.com")

            DSButton("Sign in", isFullWidth: true) {
                isSubmitting = true
                DSToastManager.shared.success("Signed in")
            }
            .loading(isSubmitting)

            HStack {
                DSAvatar(name: "Ada Lovelace", status: .online)
                DSStatusBadge("Verified", variant: .success)
            }
        }
        .padding(SpacingTokens.Layout.screenEdge)
        .frame(maxWidth: .infinity, maxHeight: .infinity)
        .dsBackgroundColor(ColorTokens.Background.primary)
    }
}
```

### 选择主题

在你设置主题之前，`ThemeManager` 会跟随系统的浅色/深色设置：

```swift
// Follow the system light/dark setting (the default) ...
DesignSystemPro.configure()

// ... or force a preset or a generated brand theme.
ThemeManager.shared.setTheme(PresetThemes.ocean)

let brand = BrandConfiguration(primaryColor: .purple, secondaryColor: .pink, borderRadius: 12)
ThemeManager.shared.setTheme(WhiteLabelConfiguration(brand: brand, appName: "Acme").darkTheme)
```

你自己的视图通过 `@Environment(\.dsTheme)` 读取当前主题。内置组件直接使用颜色令牌，不会因主题而改变样式。

### 检查对比度

```swift
let ratio = ColorContrastUtility.contrastRatio(.white, Color(hex: "#2563EB")) // about 5.2
let passes = ColorContrastUtility.meetsWCAG_AA(.white, Color(hex: "#2563EB")) // true
```

## 系统要求

| 平台     | 最低版本              |
| -------- | --------------------- |
| iOS      | 17                    |
| macOS    | 14                    |
| watchOS  | 10                    |
| tvOS     | 17                    |
| visionOS | 1                     |
| 工具链   | Swift 6.0 · Xcode 26+ |

CI 使用 Xcode 26.6 构建，开发使用 Xcode 27。`DSTextArea` 使用了 `TextEditor`，因此在 tvOS 和 watchOS 上不可用。

## 架构

```text
Sources/DesignSystemPro
├── Tokens/      ColorTokens, TypographyTokens, SpacingTokens, BorderTokens, ShadowTokens, AnimationTokens
├── Theme/       DSTheme, ThemeManager, DSThemeProvider, presets, brand/white-label generation
├── Components/  Buttons, text input, selection, cards, badges, avatars, toasts, skeletons
└── DesignSystemPro.swift   configure() and DSApp
```

| 系列     | 视图                                                                                                       |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| 按钮     | `DSButton`（6 种样式、5 种尺寸、图标、加载状态）、`DSIconButton`、`DSButtonGroup`                          |
| 文本输入 | `DSTextField`（校验状态、安全输入）、`DSTextArea`、`DSSearchField`、`DSOTPField`                           |
| 选择     | `DSToggle`、`DSSwitch`、`DSCheckbox`、`DSCheckboxGroup`、`DSRadio`、`DSRadioGroup`                         |
| 内容     | `DSCard`、`DSCardHeader`、`DSCardFooter`、`DSStatCard`、`DSMediaCard`、`DSListCard`、`DSCardListItem`      |
| 徽章     | `DSBadge`、`DSCounterBadge`、`DSDotBadge`、`DSStatusBadge`、`DSTag`                                        |
| 头像     | `DSAvatar`（图片、姓名首字母或占位图，带状态点）、`DSAvatarGroup`、`DSBorderedAvatar`、`DSAvatarWithBadge` |
| 反馈     | `DSToastManager` 搭配 `DSToastContainer`/`DSToastView`、`DSSnackbar`                                       |
| 加载     | `DSSkeleton` 以及文本、头像、卡片、列表、表格和个人资料骨架屏；`DSConditionalSkeleton`                     |

- 组件由令牌构建，不读取主题。令牌都是普通的 `Sendable` 值类型。
- `ThemeManager` 和 `DSToastManager` 是 `@MainActor` `@Observable` 类，既有共享实例，也有公开的初始化方法，因此可以注入（`DSThemeProvider(themeManager:)`、`DSToastContainer(manager:)`）并进行测试。
- 测试（`swift test`）使用 Swift Testing，覆盖令牌计算、对比度、主题解析、Toast 队列和计时器、组件辅助函数、文档中的代码片段、每组组件在浅色和深色模式下的参考指纹，以及在 AppKit 中托管的视图（用于检查主题提供者、开关颜色和 OTP 焦点框）。CI 还会在 iOS 模拟器上运行这些测试。

## 路线图

- 为 2.0.0 打标签，并根据 [CHANGELOG.md](CHANGELOG.md) 发布版本说明。
- 让组件读取当前主题，使预设主题和品牌主题也能改变组件样式。
- 将浅色调色板颜色上的头像首字母，以及深色模式下复选框勾号的对比度提高到 WCAG AA。

2026 年 6 月，这个软件包曾被精简为占位文件；2.0 恢复了此前的令牌、主题引擎和组件，修复了恢复过程中发现的问题，并补充了测试。1.x API 中的组件（警告框、模态窗口、导航栏、标签栏、图表）没有恢复。欢迎以 [issue](https://github.com/muhittincamdali/SwiftUI-Design-System-Pro/issues) 的形式提出想法和报告问题。
