# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

DesignSystemPro is a UI library: it does not store data, make network
requests or handle credentials. If you still find a security issue, please
report it privately through
[GitHub security advisories](https://github.com/muhittincamdali/SwiftUI-Design-System-Pro/security/advisories/new)
instead of opening a public issue. Include the affected version and steps to
reproduce.
